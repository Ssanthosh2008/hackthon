> **Hackathon Problem Statement Addressed:**  
> **“Digital Platform for Centralized Alumni Data Management and Engagement”**

ALUMNEX is a production-quality, modern, and highly usable digital platform designed to centralize alumni data management and continuously connect **Students ↔ Alumni ↔ Institution ↔ Mentors ↔ Events ↔ Opportunities**.

---

## 🌟 Key Features & Sections

1. **🏠 Modern SaaS Landing Page**
   - Interactive ALUMNEX Knowledge Network connection graphic.
   - Real-time trust metrics (12,450+ total alumni, 8,920+ active alumni, 450+ mentors, 24+ upcoming events).

2. **🔍 Section 1 — Smart Alumni Directory**
   - Multi-faceted search by name, role, company, skills, or bio.
   - Filter dropdowns by Department, Graduation Year, Location, Industry, and Mentorship Availability badge.

3. **👤 Section 2 — Detailed Alumni Profile Pages**
   - Slide-over profile view showing career journey timeline, academic background, skills, open-source projects, achievements, and direct message/mentorship request triggers.

4. **🧠 Section 3 — Smart Mentorship Matching ("Find My Mentor")**
   - AI-powered matching algorithm calculating compatibility scores (e.g., **96% Match**) based on career goal, interested domain, skills, preferred location, and mentorship format.
   - Displays clear explanation cards for why the mentor is recommended.

5. **📅 Section 4 — Events & Engagement Hub**
   - Event discovery system supporting Alumni Meets, Career Talks, Workshops, Networking Reunions, Webinars, and College Events.
   - Real-time event registration toggles with instant state updates.

6. **💬 Section 5 — Professional Networking Hub**
   - Community feed with likes, comments expander, share links, save post bookmarks, and new post creation.

7. **💼 Section 6 — Job & Opportunity Board**
   - Exclusive internships, full-time jobs, direct alumni referrals, and freelance gigs posted by verified alumni.

8. **📊 Section 7 — Student Dashboard**
   - Career Progress Tracker bar (% profile completion, mentorship sessions, connections, events attended, applications).

9. **🏆 Section 8 — Alumni Dashboard**
   - Pending student mentorship requests queue with instant **Accept** / **Decline** actions and profile contribution stats.

10. **🏛️ Section 9 — Admin / Institution Dashboard**
    - Centralized institutional analytics (department distribution, grad year breakdown, active engagement rate).
    - **Alumni Data Verification Queue:** Institutional verification workflow supporting **Approve**, **Reject**, and **Request Update** actions.

11. **🔔 Section 10 — Smart Notifications & Section 11 — Global Search**
    - Notification center drawer and universal `Ctrl+K` search across the entire platform.

12. **⚡ Innovation Layer — ALUMNEX Smart Insights**
    - Intelligent recommendation widget displaying top mentor matches, event recommendations, and high-match job referrals.

## 🛠️ Technology Stack

- **Frontend Framework:** React 19 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4 + Vanilla CSS animations & glassmorphism
- **Iconography:** Lucide React
- **Data Structure:** PostgreSQL-ready schema interfaces & modular frontend services

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Ssanthosh2008/hackthon.git
cd hackthon

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser to view the app.

### Build for Production
```bash
npm run build
```
